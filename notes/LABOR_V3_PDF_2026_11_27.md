## Result and protected behavior

accepted action. Download Proposal then exposes the saved private PDF for repeat
download, with the established red PDF icon. Existing Set Prices confirmation,
price-edit invalidation, object approval, quantities, costing, navigation, auth,
private storage and previously generated PDFs remain protected.

Owner-approved before/after changes:

  V3: approved native A4 layout, whole-ILS Project display, embedded app/Hebrew fonts,
  frozen company/project metadata and logo, descriptions and shared saved crops.
- Old Generate created the PDF for the separate Download action. V3 also requests
  its first browser download after durable file and reference success.
- Header uses only the complete uploaded company logo. Company Name/subtitle are
  never separately typeset. Remove only the known normalized Profile preview-card
  frame/empty margins, preserving the actual logo, icon and embedded wordmark.
- Footer attribution has two right-aligned rows: `estimated with` above the smaller

  use the same physical right edge. Company legal names are omitted from the footer;
  registration/bank details start directly below its divider. Client/Partner are conditional; social links are omitted.
- Set Prices validates the saved basis and retains its deep copy. Generate uses it
  without another full estimate load or recalculation. Pure basis matching and the
  existing server ownership/finalization transaction remain required.

## Data contract

`project_versions.snapshot.document` extends the existing private JSON snapshot:
`template`, `issued_at`, owning company/run IDs, whitelisted company Profile,
project/client/partner metadata, frozen normalized logo bytes (base64), immutable
content-addressed Detection preview references. No new table, column, RPC, bucket,
AI call or model recognition was added. Source fields are in the existing
`companies`, `rfq_runs`, estimate rows/project costs/summary and overhead settings.

Logo bytes are frozen because Profile replacement deletes the previous logo.
On retry render the stored version snapshot, rather than new Profile/price values.
An existing saved PDF is returned without republishing. Financial calculations
remain unchanged; printing uses the same whole-ILS rounding convention as Project.
Explicit zero advance differs from NULL. Dates/15 days/70%/ADA and demo company
values are not hardcoded template data. Requisites omit absent fields.

Private previews are selected once for the run and owning objects, checked against
company/run/object prefixes, then downloaded from the existing evidence store.
WebP is converted losslessly to a PDF-supported PNG. Previews inherit the existing
accepted crop, including previously deferred neighbour-fragment/padding limitations;
this release does not introduce segmentation or alter Detection evidence.

## Interaction and diagnostics

The existing Objects action listener shows disabled `GENERATING…` immediately on
an accepted native click. Only Generate is changed. A failed callback changes its
existing action identity so an enabled retry is rendered; no polling/timer/worker
or new visible notice was introduced. The listener has the existing scoped cleanup.

A zero-layout download component is emitted only after saved URL success, performs
one browser download, and records a per-action token in tab session storage to
avoid repeated script execution downloading again. Later Download uses the same
signed URL. Source/reference/write failures retain retry and never report success.
Shared asynchronous RuntimeTrace events separate accepted action, source reads,
version freeze, preview downloads, rendering, storage upload, reference save,
completion and failure. They contain IDs/durations, not document/company/bank data.
Persisted production telemetry and authenticated owner behavior require acceptance.
