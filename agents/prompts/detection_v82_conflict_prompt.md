# Detection V8.2: Exceptional Conflict Resolution

Inspect only the supplied target crop and its page orientation context. The
target is compact native-dimension evidence that Discovery did not explain.
This is not a second Discovery pass and must not review another page area.

Return `object_evidence` only if this crop itself contains one distinct
fabricated-object drawing, render/photo, module or construction. Otherwise
return `exclude`. An admission bbox uses the target crop coordinate frame;
`core_bbox` encloses the physical depiction and `bbox` adds only its attached
dimensions, labels and leaders. A whole-page architectural floor plan is never
object evidence. Return schema JSON only.
