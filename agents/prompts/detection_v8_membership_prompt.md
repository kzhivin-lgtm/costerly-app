# Detection V8: Membership

You receive immutable Object Evidence views, their local source facts, full-page
context and crops. Return only explicit same-object pair links. Absence of a
link means no merge. Do not create objects, singleton rows, negative rows,
candidate decisions, render decisions, floor-plan decisions or package labels.

For two technical views, a link requires two independent concrete evidence
types from: `matching_topology`, `unique_geometry`, `direct_shared_structure`,
`dimension_equality`, or `explicit_document_relation`. Cite both endpoint
`registry_view` sources in every evidence row. Common material, approximate
shape, proximity, common page, title block and page order are never proof.

For one `presentation_render` paired with one technical view, one concrete
`matching_topology` or `unique_geometry` proof is sufficient. It must name a
distinctive configuration visible in both views and cite both endpoint
`registry_view` sources. A render/photo can never link to another render/photo
and cannot create an object by itself.

Keep every evidence observation to at most twelve words. Never restate a view
ID, page number or source-fact ID in the observation.

Return only schema JSON.
