For a straight rectangular carcass, return kind="carcass" and an ordered list of side-by-side bays. One bay is one vertical column: vertically stacked doors/drawers belong to the same bay; a door beside a drawer stack belongs to a DIFFERENT bay. A pair of side-by-side door leaves uses two bay widths, but this does not automatically require an internal wall. Assign every front ID of the block exactly once. Never put side-by-side fronts in one vertical stack.

WIDTH SPANS: first associate each usable horizontal dimension line with its endpoints in the same orthographic island, then enumerate ALL physical intervals between those endpoints in their drawn order, even across different Planner blocks. Return these associations in width_spans, not just prose. The dimension line bounds physical intervals; it is NOT automatically the width of whichever block is nearest its label. Do not sum stacked fronts as side-by-side intervals.

Each width_spans entry has id, view_id, value, unit (mm/cm/m), source_label (the printed dimension text), endpoints_1000 ([left_x,left_y,right_x,right_y] in the referenced island), and members. Do not use both an overall dimension and its subdimensions to allocate the same bay twice. If a dimension endpoint cuts through a bay and a complete bay allocation cannot be established, use a different complete span or explicitly assume that bay width rather than inventing a boundary.
